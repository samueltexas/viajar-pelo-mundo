# Security Policy

## Supported Versions

This project is under active development.
Security fixes are applied to the latest version.

## Reporting a Vulnerability

Please do not publish exploit details in public issues.

Report suspected vulnerabilities privately through
GitHub's private vulnerability reporting feature,
if enabled for this repository.

## Security Practices

- Credentials must not be committed to Git.
- Production and test credentials must be separated.
- Database access must be restricted.
- Dependencies should be updated regularly.
- Authentication and authorization must be tested.
- Sensitive information must not appear in logs.

## Disclaimer

This is a portfolio project and is not intended
to process real payments or sensitive travel documents.
